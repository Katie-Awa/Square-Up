# Update Version 0.1.8.1

## What's Changed?

### New Weapon!

**Flintlock Pistol**
* The flintlock pistol has been added into the game as a replacement for the soon depricated golden gun

### New Shop!
**Carl's Finest**
* Being the now new default starting shop, this shop will have all the cheap and someone goofy weapons of Square up.

### Audio Engine rework.
The audio engine has been reworked meaning that missing sounds are to be expected.
